## Proyectos

**[Turnera](https://github.com/DiegoPistorio/turnera)** — Sistema de turnos para peluquería. Los clientes reservan y pagan una seña; el personal gestiona la agenda desde un panel propio. Stack: Next.js · TypeScript · PostgreSQL · MercadoPago · Docker. Demo en vivo: [turnera-opal.vercel.app](https://turnera-opal.vercel.app)

**[App Riders](https://github.com/DiegoPistorio/app-riders)** — Control de ganancias para repartidores en moto. Registra ingresos por app, efectivo y particulares; gastos por categoría; y muestra un mapa de calor con las zonas de más trabajo. Stack: Next.js 15 · TypeScript · Tailwind CSS · PostgreSQL · Leaflet.
